# 静读 JingDu

一个简洁的中文在线小说阅读网站，为 BiUH Web Technologies 2026 期末作业而做。

## 功能

- 首页书架：展示多本书，每本显示阅读进度。
- 书籍详情页：封面、简介、开始阅读、章节目录预览。
- 阅读页：干净的书本式排版，支持上一章/下一章和键盘翻页。
- 主题切换：浅色、暖色、深色三种主题，自动保存偏好。
- 字号调节：A- / A / A+，自动保存。
- 阅读进度：每本书独立记录读到哪一章，首页显示总进度。
- 响应式布局：适配手机和桌面。

## 文件结构

```
outputs/
├── index.html       # 书架首页
├── book.html        # 书籍详情页
├── read.html        # 章节阅读页
├── toc.html         # 单本书目录页
├── about.html       # 关于本站
├── css/
│   └── style.css    # 全部样式、主题、响应式布局
├── js/
│   └── app.js       # 书架数据、主题/字号/进度逻辑
├── server.js        # 本地预览服务器
└── README.md        # 本文件
```

## 如何预览

在 `outputs` 文件夹中运行：

```bash
node server.js
```

然后浏览器打开 http://localhost:8080。

也可以直接双击 `index.html` 用浏览器打开（部分浏览器可能因本地文件限制导致 URL 参数不生效，建议用服务器方式）。

## 如何换成你自己的小说

1. 打开 `js/app.js`。
2. 找到顶部的 `books` 数组。
3. 修改现有书籍的 `title`（书名）、`author`（作者）、`synopsis`（简介）、`coverGradient`（封面渐变）和 `chapters`（章节）。
4. 添加新书时，给一个新的唯一 `id`，并保证每本书内部的章节 `id` 从 1 开始连续递增。
5. 保存后刷新浏览器即可看到新书。

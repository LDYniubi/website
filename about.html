关于静读

这个网站

静读是一个简洁的中文在线小说阅读网站。首页是书架，可以浏览多本书；点击书封进入书籍详情页，再选择开始阅读或查看目录。阅读页支持字号调节、主题切换和章节跳转。

网站使用纯 HTML、CSS 和 JavaScript 构建，没有引用任何外部框架或库，方便理解和修改。

技术要点

  • 语义化 HTML：使用正确的标题层级、landmark 和 ARIA 标签。
  • 响应式 CSS：针对手机和桌面屏幕做了适配。
  • CSS 变量：浅色、暖色、深色三套主题共用一份样式表。
  • 渐进增强：没有 JavaScript 时页面仍能显示基本内容；开启 JavaScript 后增加主题记忆、字号调节和进度保存。
  • 可访问性：包含跳转链接、可见的焦点状态和键盘导航。

如何换成你自己的内容

打开 js/app.js，找到顶部的 books 数组。每本书包含标题、作者、简介、封面渐变色和章节数组。你可以修改现有书籍，也可以按相同格式添加新书。

添加新书时，注意给它一个唯一的 id，并保证每本书内部的章节 id 从 1 开始连续递增。
